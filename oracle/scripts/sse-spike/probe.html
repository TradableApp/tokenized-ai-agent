SSE probe: browser check

Opens the probe stream with fetch from this page's origin, with a Last-Event-ID header so the browser must send a CORS preflight first. Prints each frame's delay (arrival minus server send time, clock skew removed) and a summary. Read the HTTP version from the devtools Network tab, Protocol column. No dependencies. See RUNBOOK.md, step "browser check", for how to open it without deploying anything.
